# Example photos

Photos of items that are typically sold second-hand. Use them to test the
tools and the agent without taking your own picture:

```sh
npm run test:tools -- examples/photos/game-boy.jpg
```

All five come from Wikimedia Commons and are in the public domain or released
under CC0, so you may use them without attribution. They are scaled down from
the originals. Brand names and logos in the pictures belong to their owners.
